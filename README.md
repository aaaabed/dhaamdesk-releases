## طريقة الاستخدام

1. حمّل وثبّت البرنامج
2. افتح DhaamDesk — سيظهر لك **ID** و**كلمة مرور** تلقائياً
3. للاتصال بجهاز: أدخل ID الجهاز الآخر واضغط **Connect**
4. لمشاركة جهازك: أعطِ الطرف الآخر الـ ID وكلمة المرور

## الدخول بحساب

سجّل دخولك داخل البرنامج (أيقونة الحساب) لحفظ أجهزتك ومزامنتها عبر كل أجهزتك.

## التحديث التلقائي

البرنامج يتحقق من التحديثات تلقائياً ويعرض تنبيهاً عند توفر إصدار جديد — التحديثات موقّعة ومتحقق من سلامتها قبل التثبيت.
